# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1. The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## In short

Everyone participating in this project is expected to act respectfully and in good faith.
Harassment, personal attacks, discriminatory language, and other unprofessional conduct are
not tolerated in issues, pull requests, discussions, or any other project space.

## Enforcement

Report unacceptable behaviour privately to **harsh.ju.sharma@gmail.com**. Reports are handled
confidentially, and maintainers will respond as promptly as they reasonably can.

Maintainers may remove comments, commits, code, issues, and other contributions that violate
this Code of Conduct, and may temporarily or permanently ban any contributor for behaviour they
deem inappropriate.
